# Couleuvre

## Description (français)

Une espèce inconnue de couleuvre a été découverte dans la forêt à proximité du camp.
Ces petits serpents sont plutôt lents et semblent inoffensifs, mais ils sont très curieux et aiment s'introduire dans les affaires des campeurs.

Afin de mieux comprendre ces créatures, nous devons les étudier de plus près pour découvrir leur ssssssecret.
